# Project Feedback Questions for Novice Users

1. What best describes you?
2. Have you traded before, or are you only interested in learning?
3. Do you understand that this bot is for education/demo use only?
4. Does the bot explain risk clearly before any recommendation?
5. Does the ML probability make the recommendation easier or harder to understand?
6. Does the VSA explanation help you understand why a setup appeared?
7. Would you use this as a learning/demo tool rather than real-money advice?
8. What part of the project looks most useful?
9. What part looks most risky or confusing?
10. What should be improved before this is shown to more users?
